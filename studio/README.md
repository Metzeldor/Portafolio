# Web & AI Studio — Andrés Tejada

Landing page de servicios profesionales para presentar soluciones de desarrollo web y agentes de inteligencia artificial personalizados.

## Demo

[🌐 Ver sitio publicado](https://metzeldor.github.io/Portafolio/studio/)

## Objetivo

Presentar una oferta de servicios digitales con una experiencia visual premium, una jerarquía clara y llamadas a la acción orientadas a iniciar conversaciones comerciales.

## Servicios presentados

- Desarrollo de sitios web, landing pages y páginas corporativas.
- Diseño responsive y experiencia de usuario.
- Agentes conversacionales de IA personalizados.
- Automatización de atención, captura de prospectos e integración con canales digitales.

## Características

- Diseño oscuro con acentos violeta, cian y lima.
- Composición editorial, tipografía moderna y microinteracciones.
- Hero visual con mockups de web y asistente de IA.
- Secciones de servicios, enfoque, proceso, proyectos y contacto.
- Navegación móvil desplegable.
- Animaciones de entrada con soporte para `prefers-reduced-motion`.
- SEO básico y metadatos Open Graph.
- Enlace de contacto directo a WhatsApp.

## Tecnologías

HTML5 · CSS3 · JavaScript vanilla · Google Fonts

studio/

## Ejecución local

No requiere instalación ni dependencias.

1. Clona el repositorio.
2. Abre `studio/index.html` en el navegador, o sirve la carpeta con cualquier servidor estático.
