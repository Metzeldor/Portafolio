## 🚀 Proyectos destacados

### 1. ClientFlow — CRM para pequeños negocios

Aplicación web para organizar contactos y oportunidades comerciales desde un panel sencillo.

- Registro, edición, búsqueda y filtrado de clientes.
- Pipeline de ventas por etapas.
- Resumen de oportunidades y valor potencial.
- Exportación de contactos a CSV.
- Persistencia local con `localStorage`.

**Stack:** HTML, CSS y JavaScript.

[▶ Abrir demo](https://metzeldor.github.io/Portafolio/clientflow/) · [Ver código y documentación](./clientflow/)
